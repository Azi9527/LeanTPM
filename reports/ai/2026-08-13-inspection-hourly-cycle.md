# 点检方案“每小时”周期支持

## 需求与验收

- 点检方案的周期类型新增“每小时”（`HOURLY`）。
- “周期间隔”在每小时时显示为“间隔小时”，“计划时间”显示为“首次计划时间”。
- 每小时周期按 `首次计划时间 + N 小时` 推进，必须支持跨午夜。
- 每次推进同时持久化下一执行日期和下一执行时间，同一天的不同小时使用不同发生键。
- 未允许补录时，不批量生成当前时刻以前已经错过的小时任务；允许补录时保留原补录语义。
- 原有每日、每周、每月、间隔天数保持不变。
- Excel 点检导入模板同步接受“每小时”。

## 风险与影响

- 风险等级：L2。
- GitNexus 修改前分析：`generateReady` 为 HIGH，直接调用者 3 个，涉及自动生成、手动生成及相关点检流程；已将改动限定在点检计划发生时间推进及其 Mapper 参数。
- `nextOccurrence`、`InspectionImportService` 为 LOW；前端 `SchemeVersionRow` 为 MEDIUM。
- 不修改数据库结构。`inspection_plan` 已有 `next_generation_date DATE` 与 `scheduled_time TIME`，组合即可表达小时级下一执行时间。
- 不涉及 APP。

## 实现

- Backend DTO 与导入逻辑增加 `HOURLY`。
- 点检任务生成由仅跟踪日期调整为跟踪 `LocalDateTime`。
- 小时周期按 `cycleInterval` 小时推进并支持跨日。
- 小时任务截止时间为下一周期前一秒；其他周期仍截止计划当天 `23:59:59`。
- `updatePlanGeneration` 同时保存下一日期与下一时间。
- Web 方案与计划页面增加“每小时”，计划列表显示下一日期和时间。
