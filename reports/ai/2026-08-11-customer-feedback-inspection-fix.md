## 需求理解与 Given / When / Then

### 1. APP 设备点检入口

- Given 用户打开设备现场信息页，When 页面加载成功，Then 只显示一个可展开/收起的“管理信息”卡片。
- Given 管理信息已展开，When 查看设备资料，Then 显示所属组织、安装位置、设备负责人、型号、生命周期、设备标识及非空备注；不显示状态时间、档案更新时间、规格、品牌、制造商、出厂编号、资产编号、生产日期、投产日期和纳入 OEE。
- Given 用户查看现场作业，When 页面渲染，Then 保留直接点检报告和可执行任务，不显示自定义创建点检任务及可用点检模板。

### 2. 未完成任务扫码校验

- Given 任务状态为待执行、执行中或逾期，When 用户从点检列表、工作台、设备现场任务或消息入口进入任务，Then 统一先进入扫码页而不是点检详情。
- Given 扫码设备与任务设备一致，When 扫码解析成功，Then 进入该任务的点检详情。
- Given 扫码路由参数陈旧或被修改，When 扫码校验，Then 以服务端任务详情中的状态和设备 ID 为准，不信任路由中的设备 ID。
- Given 扫码无效或设备不一致，When 校验完成，Then 留在扫码页并显示明确错误，任务状态不改变。
- Given 任务已完成，When 用户点击任务卡片，Then 仍可直接查看详情。

### 3. 点检方案复制/删除

- Given 任一方案，When 用户复制，Then 打开新方案表单，清空方案编码、名称追加“（副本）”、复制当前版本内容，保存后创建独立方案且源方案不变。
- Given 方案已停用且没有启用计划，When 用户确认删除并提交正确版本号，Then 仅软删除方案主记录，保留方案版本、计划、任务和审计历史。
- Given 方案仍启用、有启用计划或版本冲突，When 用户删除，Then 后端拒绝并返回业务错误。

### 4. 项目分类字典

- Given V50 数据库，When 执行 V51，Then 为每个有效租户启用保留字典 `inspection_item_category`，并确保传动、润滑、紧固、电气、安全防护、其它六个保留值存在且启用。
- Given 租户在 V51 前已创建同编码类型或同值项目，When 执行 V51，Then 保留自定义名称、标签、排序和默认标记，仅恢复保留类型/值的启用状态；额外自定义值不删除。
- Given 新建/编辑点检项目，When 打开分类字段，Then 使用中文下拉且从业务只读接口加载启用字典项。
- Given V51 字典缺失或接口返回空，When 页面加载，Then 使用六项内置回退值。
- Given 历史项目含旧分类值，When 编辑，Then 旧值作为兼容选项显示，不被静默改写。

## 影响与风险

- APP：设备信息展示、点检任务导航、扫码校验；不修改移动 API 合同。
- 前端：点检方案与点检项目页面、点检 API 客户端。
- 后端 API：新增分类只读接口、方案软删除接口；沿用现有点检查看/管理权限。
- 数据库：新增 V51 数据迁移，不改表结构、不改现有点检项目值、不触碰 `flyway_schema_history`。
- 权限：字典维护仍需系统字典权限；点检页面读取分类仅需 `inspection:item:view`。
- 部署：仅更新版本/兼容性声明，不执行发布。
- 风险等级：L4。原因是生产 Schema 从 V50 演进到 V51，虽为可重复语义的数据补种，仍需完整迁移、备份恢复和回滚兼容验证。

## 数据保护与回滚

- 迁移前验证隔离备份可恢复；不得在生产试跑 SQL。
- V51 不删除业务数据。应用回滚到期望 V50 的旧版本会因 readiness 的精确 Schema 校验而不可直接运行，因此迁移分类的 `backwardCompatible` 为 `false`；默认回滚方式是恢复 V50 隔离备份，或使用经评审的前向修复版本。
- 全新安装验证 V1→V51；升级验证 V50→V51；隔离实例验证重复执行与多租户/已有自定义字典场景。

## 迁移分类评审证据

- 分类：`MIGRATE`；无需停机执行 SQL 本身，但发布流程必须停在显式迁移/恢复门禁内。
- `requiresDowntime=false` 仅描述该数据补种 SQL 不要求独占停机；不代表整体发布零停机。由于旧 Backend readiness 不接受 V51，正式迁移、应用切换和健康检查仍必须处于受控服务窗口。
- 向后兼容：`false`。原因不是表结构破坏，而是旧 Backend 的精确 Schema readiness 只接受 V50，不能直接运行在 V51。
- 本地候选评审：`APPROVED` 仅表示 V51 SQL 已获用户明确授权并通过本任务静态/隔离评审，不代表已获提交、推送或生产发布授权。
- SQL 结论：仅操作租户字典类型和字典项；不更新 `inspection_item`，不删除方案/计划/任务，不修改 `flyway_schema_history`。
- 保留字典策略：V51 恢复 `inspection_item_category` 类型和六个稳定值的启用状态，同时保留既有中文标签、排序、默认项及额外自定义值。
- 回滚门禁：必须先有 V50 隔离备份并完成异库恢复验证；不能让旧版本直接连接 V51。
