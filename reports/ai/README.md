# AI 工程证据目录

本目录保存 AI 开发流程产生的可审计证据。完整要求见[通用 AI 开发流程](../../docs/ai/development-workflow.md)。建议每个任务使用独立目录：

```text
reports/ai/<date>-<task-slug>/
├─ task.md
├─ tests/
├─ browser/
├─ api/
├─ database/
├─ impact/
├─ cleanup/
└─ logs/
```

可保存内容：

- 测试报告和机器可读结果；
- 浏览器截图、trace、控制台和网络摘要；
- API 合同与集成验证摘要；
- 数据库只读验证、迁移与完整性检查报告；
- GitNexus 或其他影响分析结果；
- 自动清理报告；
- 不适合放入对话的长日志。

禁止保存：

- 密码；
- Token；
- Cookie；
- 私钥或签名材料；
- 完整生产数据；
- 未脱敏个人信息；
- 可直接复用的生产连接字符串；
- 与任务无关的用户文件。

报告应优先保存摘要、哈希、计数和脱敏样例。若原始工具输出含秘密，先在安全位置脱敏，不得先写入本目录再删除。

清理报告至少记录：任务标识、清理目标、精确路径或数据标识、创建者、清理命令、结果、残留和验证时间。任何无法证明由当前任务创建的资源均不得自动删除。
