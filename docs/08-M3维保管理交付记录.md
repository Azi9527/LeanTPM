# LeanTPM M3 维保管理交付记录

## 1. 交付结论

M3「维保管理」已完成项目、版本化方案、周期计划、任务状态机、PC/移动执行、备件耗用、异常、统计和设备状态联动。

本阶段形成可运行链路：

> 维保项目 → 方案草稿/发布 → 设备计划 → 日历/累计值触发 → 派工/转派/协同 → 开始/暂停/恢复 → 项目结果/前后照片/备件 → 完工 → 管理确认/退回 → 异常闭环 → 归档

## 2. 数据库迁移

新增不可变迁移 `V10__maintenance_management.sql`，共 16 张业务表：

| 领域 | 表 |
|---|---|
| 项目 | `maintenance_item` |
| 方案 | `maintenance_scheme`、`maintenance_scheme_version`、`maintenance_scheme_item`、`maintenance_scheme_category`、`maintenance_scheme_equipment` |
| 计划 | `maintenance_plan` |
| 任务 | `maintenance_task`、`maintenance_task_item`、`maintenance_task_result`、`maintenance_task_collaborator`、`maintenance_task_pause`、`maintenance_task_event` |
| 耗材、异常与附件 | `maintenance_material_usage`、`maintenance_abnormal`、`maintenance_attachment` |

关键约束：

- `(tenant_id, plan_id, occurrence_key)` 保证同一计划周期幂等；
- 任务项目复制方案版本标准，后续方案变更不覆盖历史任务；
- 暂停履历独立记录，恢复时累计暂停秒数，完工工时自动剔除暂停时长；
- 备件数量、单价和总价均使用 `DECIMAL`；
- 前照片、后照片和普通附件使用独立附件类型；
- 计划、任务、项目、方案、异常和备件记录使用乐观锁；
- V10 同步交付字典、参数、编号规则、菜单、按钮权限和演示数据。

## 3. 维保规则

- 维保等级支持日常、一级、二级、三级、专项和年度保养；
- 周期支持日、周、月、季度、半年、年、运行小时、生产数量和手工触发；
- 运行小时和产量由人工维护累计值，为 IoT 数据源预留统一入口；
- 计划支持暂停、恢复、取消和批量生成；
- 任务状态为待派工、待执行、执行中、已暂停、待确认、已完成、已逾期、已取消和已作废；
- 非法状态跳转、无执行人启动、非执行人/协同人作业均由后端拒绝；
- 派工接口同时支持转派，协同人员可在本人数据范围访问并执行跨组织任务；
- 需停机任务开始时将设备切换至 `MAINTENANCE`，确认或关闭后按方案恢复状态；
- 结果支持数值、合格、不合格、文本、选项、异常说明、跳过、前后照片和附件；
- 项目异常自动形成维保异常记录，可处理、验证并联动设备状态；
- 统计提供今日应保、完成、待办、逾期、异常、完成率和按时率。

接口前缀：`/api/v1/maintenance`。

| 资源 | 主要接口 |
|---|---|
| 项目 | 查询、详情、新增、修改、停用删除 |
| 方案 | 查询、详情、新建、创建版本、发布 |
| 计划 | 查询、暂停/恢复/取消、累计值维护、批量生成 |
| 任务 | 查询、详情、手工创建、派工/转派、协同、开始、暂停、恢复、草稿、完工、确认/退回、取消/作废 |
| 备件 | 新增、修改、删除任务备件耗用 |
| 异常 | 查询、处理、验证 |
| 统计 | 维保核心指标 |

所有写接口启用认证、后端功能权限、数据范围、参数校验和统一幂等键。
