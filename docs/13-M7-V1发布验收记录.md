## 4. 安全强化

- CORS 来源由 `LEANTPM_CORS_ALLOWED_ORIGINS` 显式配置；
- HTTPS 响应启用 HSTS，并返回 CSP、DENY Frame、no-referrer、Permissions-Policy 和 nosniff；
- 生产可通过 `LEANTPM_OPENAPI_ENABLED=false` 关闭 OpenAPI；
- 上传回归覆盖可执行扩展名、超限负载和注入式业务类型；
- 未认证移动 API 返回 401，未列入 CORS 白名单的来源返回 403；
- MyBatis 使用参数绑定，业务编码输入执行格式白名单；
- Vue 模板默认转义动态文本，CSP 限制对象、框架和外部资源；
- Android 正式清单禁止明文 HTTP，令牌和草稿使用 Android Keystore AES/GCM。

上述为自动化安全基线，不替代上线前的企业 SAST、DAST、病毒扫描和独立渗透测试。
