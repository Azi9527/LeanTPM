## 3. 计算与业务规则

所有指标均在后端计算，前端只提交原始数据并展示结果：

- 负荷时间 = 计划工作时间 − 计划停机时间；
- 时间开动率 = 运行时间 ÷ 负荷时间；
- 性能开动率 = 标准节拍 × 实际产量 ÷ 运行时间；
- 良品率 = 良品数量 ÷ 实际产量；
- OEE = 时间开动率 × 性能开动率 × 良品率。

性能率是否按 100% 封顶由 `oee.performance-cap-enabled` 控制，单条计算、趋势、汇总和排名使用同一参数。性能率超过 100%、负荷时间无效、非计划停机超过负荷时间或实际产量为 0 时形成异常并阻止提交。

六大损失按影响指标处理：

- 设备故障、换型调整和其他可用性损失计入非计划停机；
- 空转短停和速度降低通过产量与节拍反映到性能率，不重复扣减时间开动率；
- 过程不良和启动不良反映到良品率；
- 计划停机从负荷时间剔除。

产量或停机源数据修订会自动重算 OEE、回到草稿状态并新增计算日志。锁定后源数据不可修改；解锁保留原审核人和审核时间。

## 4. 后端与接口

新增 `com.leantpm.oee` 领域模块：

- `OeeController`
- `OeeCatalogService`
- `OeeService`
- `OeeImportService`
- `OeeMapper` 与 XML
- `OeeDtos`

接口前缀：`/api/v1/oee`。

| 资源 | 主要接口 |
|---|---|
| 班次与日历 | 分页、详情、新增、修改、删除 |
| OEE 目标 | 分层目标分页、新增、修改、删除和生效期重叠校验 |
| 损失原因 | 层级维护、循环校验、引用保护 |
| 产量与停机 | 分页、新增、修改、删除和关联记录自动重算 |
| OEE 记录 | 手工新增/修改、Excel 模板/导入、重算、提交、审核、锁定、解锁、计算日志 |
| 分析 | 汇总卡、日/周/月趋势、企业至设备排名、损失构成和明细下钻 |

所有写接口启用认证、动作级功能权限、数据范围、Bean Validation、乐观锁和统一幂等键。审核与锁定权限分别校验，不能利用其中一个权限执行另一个动作。

## 5. Excel 导入

V1 支持 `.xlsx` 模板和批量导入：

- 设备编码、生产日期、班次编码、标准节拍、计划时间和四类产量字段；
- 支持 ISO 日期文本和 Excel 原生日期单元格；
- 单次行数由 `oee.import.max-rows` 控制，默认 2000；
- 每行独立校验设备、OEE 启用状态、数据范围、班次和数值关系；
- 返回总行数、成功数、失败数和逐行错误，成功行不会因其他行失败而丢失；
- 新增和覆盖均记录 `IMPORT` 计算日志，数据来源标记为 `EXCEL`。

MES 与 IoT 入口已通过 `source_type` 预留，本阶段不实现外部系统连接。
