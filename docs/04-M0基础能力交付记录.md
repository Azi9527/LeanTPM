## 2. 数据库交付

Flyway 迁移：`V2__system_parameters_and_number_rules.sql`

新增表：

- `system_parameter`：系统参数、值类型、分组、启停状态、内置标识和乐观锁版本。
- `system_number_rule`：编号前缀、日期格式、分隔符、流水位数和重置周期。
- `system_number_sequence`：按租户、规则和周期保存原子流水。

种子数据：

- `system.name`
- `system.timezone`
- `security.captcha.enabled`
- `EQUIPMENT`
- `INSPECTION_TASK`
- `MAINTENANCE_TASK`

所有表均包含租户、创建/更新人、创建/更新时间、逻辑删除和版本字段。自定义参数删除时保留逻辑删除记录，并释放原参数键供后续重新创建。

## 3. 后端交付

系统参数接口：

- `GET /api/v1/system/parameters`
- `POST /api/v1/system/parameters`
- `PUT /api/v1/system/parameters/{id}`
- `DELETE /api/v1/system/parameters/{id}`

编号规则接口：

- `GET /api/v1/system/number-rules`
- `POST /api/v1/system/number-rules`
- `PUT /api/v1/system/number-rules/{id}`
- `POST /api/v1/system/number-rules/{ruleCode}/generate`

核心约束：

- 参数键和规则编码创建后不可修改。
- 参数值按文本、布尔值、整数和小数执行后端类型校验。
- 修改操作使用版本字段实施乐观锁。
- 内置参数允许调整但不允许删除。
- 日期格式和重置周期使用白名单校验。
- 编号流水通过 MySQL 唯一索引、原子递增和事务行锁保证并发安全。
- 流水按每天、每月、每年或永不重置四种方式分段。
- 系统时区通过 `system.timezone` 参数统一读取。

## 4. 前端交付

新增页面：

- `/system/parameters`：查询、分组筛选、新增、编辑、启停和删除自定义参数。
- `/system/number-rules`：查询、新增、编辑、格式预览和生成正式编号。

页面覆盖：

- 加载状态。
- 空数据状态。
- 接口错误与重新加载。
- 按权限隐藏操作。
- 保存中防重复点击。
- 响应式表单和表格布局。
- 生成正式编号前二次确认。

新增权限：

- `system:parameter:view`
- `system:parameter:manage`
- `system:parameter:delete`
- `system:number-rule:view`
- `system:number-rule:manage`
- `system:number-rule:generate`
