- 增加组织、位置页面与按钮权限。

### V7：设备分类与属性

- 新增 `equipment_category`；
- 新增 `equipment_attribute_definition`；
- 属性支持 `STRING`、`INTEGER`、`DECIMAL`、`BOOLEAN`、`DATE`、`ENUM`；
- 支持单位、必填、默认值、正则、最小值、最大值和枚举选项；
- 子分类可按属性编码覆盖上级分类定义；
- 预留默认点检模板、维保模板、故障类型和 OEE 模式绑定字段。

### V8：设备台账、条码与状态

- `equipment`
- `equipment_attribute_value`
- `equipment_responsible_person`
- `equipment_transfer_record`
- `equipment_barcode`
- `equipment_current_status`
- `equipment_status_history`

关键约束：

- 设备编码在租户内唯一；
- 一台设备同时最多一个有效条码；
- 二维码仅携带 256 位随机访问令牌；
- 当前状态和历史状态独立存储；
- 扩展属性按数据类型分别存储，数值不以浮点数保存；
- 设备、分类、组织、位置和当前状态均使用乐观锁。

## 4. 前端页面

- `/master-data/organizations`：组织树；
- `/master-data/locations`：物理位置树；
- `/master-data/equipment-categories`：分类树和属性定义；
- `/equipment/ledger`：台账、动态属性、导入导出、详情、复制和调拨；
- `/equipment/barcodes`：条码生成、失效、预览、单张/批量打印；

页面具备加载、空数据、错误提示、权限控制和响应式布局。重复写入由前端幂等键和后端幂等存储共同防护。

## 5. 权限点

### 基础数据

- `master-data:organization:view/manage/delete`
- `master-data:location:view/manage/delete`
- `master-data:equipment-category:view/manage/delete`
- `master-data:equipment-attribute:manage`

### 设备

- `equipment:ledger:view/create/update/import/export/copy/transfer/status/delete`
- `equipment:barcode:view/manage/print`
- `equipment:status:view/update`

超级管理员获得全部权限；设备管理员获得除物理删除外的 M1 日常业务权限。组织范围通过统一 `DataPermissionService` 解析并作为结构化参数传给 MyBatis，接口不拼接客户端 SQL。

## 6. 业务规则

- 设备编码留空时使用 `EQUIPMENT` 编号规则生成；
- 物理位置必须属于设备所选组织；
- 生产日期不能晚于投产日期；
- 主负责人自动同步为 `PRIMARY` 责任关系；
- 分类扩展属性按定义进行类型、范围、正则、枚举和必填校验；
- 复制设备不复制出厂编号、资产编号和投产日期，新设备从规划阶段开始；
- 调拨同时记录调拨前后组织、位置和负责人；
- 已产生状态变更或调拨记录的设备禁止删除，只允许停用；
- 状态机拒绝非法跳转，当前状态乐观锁冲突返回 `409`；
- 条码重新生成和解绑会使旧令牌立即失效；
- 公共扫码接口仅返回设备编码、名称、分类、位置和当前状态。

## 9. 已知限制

- 前端生产构建仍提示主依赖包超过 500 kB，后续大屏和移动端阶段应继续拆分公共依赖；
- M1 公共扫码页仅展示最小安全信息；登录后的扫码动作和工单快捷入口将在 M2/M3/M6 接入；
- 技术文档复用 M0 统一附件关系，M1 详情可查看已关联文档；面向设备详情的专用上传交互可随文档分类需求继续增强；
- Code 128 内容为安全访问 URL，较长；现场优先使用二维码。
