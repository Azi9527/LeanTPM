# 宝山矿业品牌主题配置说明

## 1. 默认品牌

系统默认使用客户提供的宝山矿业 Logo，并采用以下标准色：

| 用途 | 名称 | 色值 |
| --- | --- | --- |
| 主品牌色 | 宝山朱红 | `#c4000a` |
| 辅助品牌色 | 宝山翠绿 | `#1c7d50` |
| 中性品牌色 | 宝山墨灰 | `#3e3a39` |

默认系统名称为“宝山矿业设备管理系统”，品牌简称为“宝山矿业”，副标题为“精益设备管理”。

## 2. 管理端配置

超级管理员进入“系统管理 → 系统参数”，在页面顶部“品牌与主题”区域可维护：

- 系统名称、品牌简称和品牌副标题；
- 品牌 Logo（PNG、JPEG 或 WebP，最大 512KB）；
- 主品牌色、辅助品牌色和中性品牌色。

保存后当前页面立即更新；未登录页面和 Android App 在下次启动或重新连接企业服务时读取最新配置。移动端离线时使用最近一次成功获取的缓存配置；首次离线启动则使用 APK 内置的宝山矿业默认品牌。

## 3. 安全与兼容

- 上传图片转换为 Data URL 存入系统参数，不依赖外部图床；
- 后端仅接受系统内相对路径或 PNG/JPEG/WebP Data URL，拒绝 SVG 与任意脚本内容；
- `V23__configurable_customer_branding.sql` 将参数值字段升级为 `MEDIUMTEXT`，并种入六项品牌参数；
- 公共接口 `GET /api/v1/public/branding` 仅返回公开品牌字段，不返回其他系统参数；
- Element Plus 主题变量、桌面导航、登录页、移动工作台、扫码页和 Android 容器统一使用同一组动态变量。

## 4. 回退方式

点击“恢复宝山默认值”后再保存，即可恢复客户提供的 Logo 与标准色。若自定义 Logo 加载失败，界面会显示品牌简称首字作为安全回退标识。
