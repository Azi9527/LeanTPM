## 2. 本轮缺陷与修复

| 编号 | 级别 | 问题 | 根因 | 修复与验证 |
| --- | --- | --- | --- | --- |
| AUDIT-001 | P0 | ZB0101 扫描本班组“装配一班”设备仍提示无权限 | `SELF` 数据范围只识别创建人、负责人和任务执行人，未包含用户主组织和多班组成员关系 | 设备与移动端 SQL 同时加入主组织、有效班组成员范围；增加员工本班组扫码、软删除成员关系失效、任务执行人授权回归用例 |

| AUDIT-003 | P1 | 上级组织范围在移动端汇总和扫码口径存在回归风险 | 汇总与设备详情分别执行 SQL，容易出现组织递归范围不一致 | 增加上级组织“本级及下级”汇总与扫码同口径集成测试 |

## 3. ZB0101 问题的数据库证据

- 账号：`ZB0101`
- 用户主组织：装配一班（`TEAM-A-1`）
- 角色：员工（`OPERATOR`），数据范围 `SELF`
- 设备：装配机器人一号（`VIZ-ROBOT-01`）
- 设备归属：装配一班（`TEAM-A-1`）
- 判定：账号和设备配置正确，原拒绝结果属于后端数据权限实现缺陷。

修复后员工数据范围规则：

1. 可访问本人主组织的设备；
2. 可访问本人加入且未删除的其他班组设备；
3. 可访问本人负责、本人被派工或协作的设备；
4. 不可访问无关组织设备；
5. 上级管理组织仍按组织树访问本级及全部下级；
6. 超级管理员仍可访问全部数据。

## 7. 非阻断性技术债务

1. 前端主包、Canvas/三维相关分包超过 Vite 默认 500 kB 告警线，建议后续独立进行懒加载和分包优化。
2. 部分旧 Flyway 脚本使用 MySQL 已弃用的 `VALUES()` 更新语法；当前可正常运行，升级 MySQL 大版本前应迁移为别名语法。
3. Mockito 当前动态加载 Java agent；当前 JDK 21 测试通过，后续 JDK 升级前应在 Maven 测试参数中显式配置 agent。
4. 本轮自动化和浏览器回归已覆盖核心权限与设备流程；Android 真机的相机、相册、弱网和离线恢复仍建议在正式验收前按测试计划执行一轮人工实机测试。
