# LeanTPM M2 点检管理交付记录

## 1. 交付结论

M2「点检管理」已完成前后端闭环、真实 MySQL 迁移、权限、自动化测试和正式本机数据库升级。

本阶段形成以下可运行链路：

> 点检项目 → 方案草稿/版本发布 → 设备计划 → 幂等任务生成 → PC/移动执行 → 草稿/提交 → 复核 → 异常整改 → 独立验证 → 设备状态联动 → 统计分析

正式本机 `leantpm` 数据库已由 V8 升级到 V9，Flyway 记录成功；正式库保留演示项目与方案，不写入集成测试设备、任务或异常数据。

## 2. 数据库迁移

新增 `V9__inspection_management.sql`，共 13 张业务表：

| 领域 | 表 |
|---|---|
| 项目 | `inspection_item` |
| 方案 | `inspection_scheme`、`inspection_scheme_version`、`inspection_scheme_item`、`inspection_scheme_category`、`inspection_scheme_equipment` |
| 计划 | `inspection_plan` |
| 任务 | `inspection_task`、`inspection_task_item`、`inspection_task_result`、`inspection_task_event` |
| 异常与附件 | `inspection_abnormal`、`inspection_attachment` |

关键设计：

- 方案发布后版本不可修改，新调整必须创建新草稿版本；
- 任务生成时复制项目名称、标准、阈值、结果类型、必填和安全说明；
- `(tenant_id, plan_id, occurrence_key)` 唯一约束保证计划时点幂等；
- 方案分类范围支持递归包含下级分类，也可精确指定设备；
- 任务结果按 `DRAFT/SUBMITTED` 分层，异常结果与异常台账一对一；
- 任务、计划和异常均使用乐观锁；
- V9 同步交付字典、编号规则、调度参数、菜单和角色权限；
- 现场角色具备点检附件上传权限。

## 3. 后端交付

新增 `com.leantpm.inspection` 模块：

- `InspectionController`：REST 接口和功能权限边界；
- `InspectionCatalogService`：项目、方案版本、发布和计划；
- `InspectionTaskService`：任务生成、手工任务、派工、执行、提交、复核和异常闭环；
- `InspectionScheduler`：按租户读取提前生成参数，周期生成任务并标记逾期；
- `InspectionMapper` 与 XML：租户隔离、组织数据范围和 MySQL CRUD；
- `InspectionDtos`：请求校验、查询结果和移动聚合模型。

核心规则：

- 项目编码、方案编码创建后不可修改；
- 数值下限不得大于上限，选择型结果必须配置选项；
- 方案至少包含一个启用项目和一个适用设备范围；
- 发布新版本会退役旧版本、取消旧版本计划并创建新计划；
- 支持日、周、月、间隔天数计划；
- 手工补录受方案配置控制；
- 数值越界必须标记异常，异常必须填写说明；
- 必填、跳过、照片和类型化结果在提交时二次校验；
- 需复核任务通过后完成，驳回后返回执行中；
- 异常按待处理、处理中、待验证、已关闭流转；
- 异常可请求设备状态联动，复用设备状态机并写入 `INSPECTION` 来源履历；
- 查询统一复用设备组织和人员数据范围。

## 4. REST 接口

接口前缀：`/api/v1/inspection`。

| 资源 | 主要接口 |
|---|---|
| 项目 | `GET/POST /items`、`GET/PUT/DELETE /items/{id}` |
| 方案 | `GET/POST /schemes`、详情、新版本、发布 |
| 计划 | `GET /plans`、状态变更、立即生成 |
| 任务 | 查询、详情、手工创建、派工、草稿、提交、复核、取消/作废 |
| 异常 | 查询、处理、验证 |
| 统计 | `GET /statistics` |

所有写接口复用统一 `Idempotency-Key` 机制，前端拦截器自动生成幂等键。

## 5. 前端与移动执行端

新增 `frontend/src/api/inspection.ts` 和 7 个动态菜单页面：

1. 点检项目：项目库、阈值和执行规则；
2. 点检方案：草稿、版本历史、适用范围、项目清单和发布；
3. 点检计划：查询、暂停、恢复、取消和立即生成；
4. 点检任务：台账、详情、派工、手工/补录、复核、取消和作废；
5. 我的点检：响应式任务卡片、类型化表单、附件、异常、跳过、草稿和提交；
6. 点检异常：责任、期限、措施、结果、状态请求和验证；
7. 点检统计：今日应检、完成、待办、逾期、异常、完成率和按时率。

页面同时注册静态安全路由，并与 V9 菜单组件路径一致。

## 6. 权限与数据范围

权限点：

- `inspection:item:view/manage/delete`
- `inspection:scheme:view/manage/publish`
- `inspection:plan:view/manage/generate`
- `inspection:task:view/create/assign/execute/review/cancel`
- `inspection:my-task:view`
- `inspection:abnormal:view/handle/verify`
- `inspection:statistics:view`

任务、计划和异常通过关联设备组织复用统一 `DataPermission`；“我的点检”额外按当前执行人过滤。
