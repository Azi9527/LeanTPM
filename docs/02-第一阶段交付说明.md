## 新增接口

- 认证：登录、刷新 Token、当前用户、修改密码、退出。
- 用户：分页查询、新增、编辑、启停、重置密码。
- 角色：查询、新增、编辑、菜单/按钮授权。
- 菜单：权限资源树。
- 字典：类型和字典项查询、新增、编辑、逻辑删除。
- 日志：登录日志与操作日志分页查询。
- 附件：分页查询、安全上传、授权下载。

## 已知问题

- 本机未发现 Redis 服务；第一阶段保留 Redis 配置，核心登录链路暂不强依赖 Redis。Redis 健康检查默认关闭，可在安装后通过环境变量启用。
- 8080 当前被本机另一 Java 程序占用，本次联调使用 18080；正式启动可通过环境变量选择端口。
- Element Plus 使首屏公共包偏大，后续阶段应按需引入组件并细分公共依赖块。
- 当前退出登录为无状态客户端退出；Redis 启用后补充 Token 黑名单和在线用户管理。
