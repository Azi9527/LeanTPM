## 6. 环境待验清单

以下项目需要客户或目标设备环境，在开发机上保持“待验”状态：

1. Android 目标机型上的相机、定位精度、水印视觉、系统通知、扫码和字体/安全区适配。
2. 真机断网拍照、加密队列、网络恢复后幂等上传和低速网络超时重试。
3. 客户正式域名的证书链、HSTS、CORS、反向代理头和 Android HTTPS 连通性。
4. 企业 keystore 的 Release APK/AAB 签名、升级覆盖安装和应用商店/MDM 分发。
5. 客户真实数据量下的 50 并发、10 万明细导出、附件容量和 RPO/RTO 演练。
6. 微信内扫描公共设备二维码的兼容性；微信内正式点检不在本轮范围。
